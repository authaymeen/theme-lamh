# لمح (Lamh) — ثيم سلة احترافي

ثيم متجر إلكتروني عام لمنصة سلة، مبني على محرك **Twilight** (Twig + SCSS + Tailwind).
هوية بصرية أنيقة ومينيمال: خلفيات بيضاء/رمادية محايدة + لون تمييز واحد (أخضر زمردي غامق `#0E7C6B`)،
مناسب لأغلب الأنشطة التجارية (أزياء، إلكترونيات، عطور، مستلزمات منزلية، إكسسوارات...).

## البنية

```
theme-lamh/
├── twilight.json              # إعدادات الثيم، الميزات، والمكوّنات المخصّصة
├── package.json / webpack.config.js / tailwind.config.js / postcss.config.js
├── src/
│   ├── assets/
│   │   ├── styles/            # app.scss + tokens + base + components + pages
│   │   ├── js/                # app.js + partials (main-menu, product-card...)
│   │   └── images/
│   ├── locales/               # ar.json / en.json
│   └── views/
│       ├── layouts/master.twig
│       ├── components/{header,footer,home,product}/*.twig
│       └── pages/              # index, product, cart, blog, brands, customer, ...
└── public/                     # ناتج البناء (مُتجاهل من git، يُنشئه webpack)
```

## المتطلبات قبل البدء

1. حساب شريك على [salla.partners](https://salla.partners).
2. حساب GitHub (سلة تربط الثيم بمستودع GitHub تلقائيًا).
3. Node.js (نسخة LTS حديثة) و **pnpm** (`npm i -g pnpm`) — الثيم مضبوط على استخدام pnpm فقط.
4. تثبيت [Salla CLI](https://docs.salla.dev/422774m0): `npm i -g @salla.sa/cli` ثم `salla login`.

## خطوات الربط والنشر مع سلة (يجب تنفيذها من حسابك — سلة تتطلب مصادقة الشريك مباشرة ولا يمكن لأداة خارجية تنفيذها نيابة عنك)

1. من بوابة الشركاء (My Themes)، اختر **"استيراد ثيم موجود من GitHub"** (وليس "Create your first
   theme" — لأن هذا المستودع موجود ومُعبّأ بالفعل) وحدد المستودع `theme-lamh`.

2. ثبّت الاعتماديات محليًا بعد استنساخ المستودع:
   ```bash
   pnpm install
   ```

3. عاين الثيم مباشرة على متجر تجريبي مع Hot Reload:
   ```bash
   salla theme preview
   ```

4. عند الجاهزية للنشر في متجر القوالب:
   ```bash
   salla theme publish
   ```
   ثم أكمل بيانات صفحة الثيم في بوابة الشركاء (الأيقونة 250×250، لقطات الشاشة، الوصف، التصنيف،
   والتسعير إن كان الثيم مدفوعًا).

## نقاط تحتاج مراجعتك قبل النشر النهائي

- **الأيقونة/الشعار**: تم توليد نسخة أولية بسيطة في `src/assets/images/theme-icon.svg`
  (ونسخة PNG 250×250) بهوية "لمح" — راجعها/استبدلها بتصميم نهائي معتمد إذا رغبت.
- **لقطات شاشة المتجر**: تحتاج تجربة حقيقية على متجر تجريبي (Service Trial) لالتقاط لقطات فعلية
  بعد الربط — لا يمكن توليدها بدون بيانات متجر حقيقي.
- **`twilight.json` مُصحَّح بالكامل الآن**: مرّ الملف بإصلاحين. الأول استبدل صيغ حقول غير معتمدة
  (`format: "color"`, `format: "select"` بخيارات نصية، `format: "category"`) بصيغ فعلية (مفاتيح
  تشغيل/إيقاف `type: boolean, format: switch`، وحقول نص/رابط/صورة موثّقة) — لكن الاستيراد استمر
  بالفشل بنفس رسالة خطأ JSON. تبيّن بعدها أن السبب الحقيقي كان في **المفاتيح الجذرية والبنية العامة**
  للملف، مقارنةً بملف `twilight.json` الحقيقي لثيم [theme-raed](https://github.com/SallaApp/theme-raed)
  الرسمي (ثيم سلة الافتراضي المُعتمَد فعليًا في المنصّة):
  - `theme_name` → أصبحت `name` وكائن ثنائي اللغة `{ar, en}` بدل نص واحد.
  - `repo_url` → أصبحت `repository` (نص عادي).
  - `support_url` (بصيغة `mailto:`) → أصبحت `author_email` (بريد مباشر)، مع إبقاء `support_url`
    كرابط دعم منفصل.
  - أُضيف حقل `description` ثنائي اللغة (اختياري لكن موجود في الثيم المرجعي).
  - أُزيلت قيمة الميزة غير الموثّقة `component-random-testimonials` من `features` (غير موجودة في
    القائمة المعتمدة من سلة).
  - كل مكوّن مخصّص في `components` أصبح يحمل `key` (UUID)، و`title` ثنائي اللغة `{ar, en}` بدل نص
    واحد، وحقل `image` (رابط معاينة — حاليًا يشير مؤقتًا لأيقونة الثيم، يُفضَّل استبداله بلقطة شاشة
    فعلية للمكوّن لاحقًا).
  - حقول المجموعات (collection) أصبحت تستخدم معرّفات بصيغة `المجموعة.الحقل` كما يتطلب سلة فعليًا،
    مثل `slides.image` و`slides.title` بدل `image`/`title` المجرّدة (ملفات الـ twig لا تحتاج أي
    تعديل — سلة يُعيد تمرير القيم للقالب بأسماء الحقول بدون البادئة تلقائيًا).

  نتيجة التبسيط الأول ما زالت قائمة: لون التمييز والخط ثابتان في الكود
  (`src/assets/styles/base/_tokens.scss`) بدل التحكم بهما من بوابة الشركاء — تقدر تغيّرهما مباشرة
  من ذاك الملف وقت الحاجة.
- **أسماء أيقونات سلة** (`sicon-*`) المستخدمة في مكوّن "مزايا المتجر": تأكد من مطابقتها لمجموعة
  أيقونات سلة الحالية من داخل بوابة الشركاء عند إعداد المكوّن.
- **الترخيص/التسعير**: هذا الثيم غير مربوط تلقائيًا بأي باقة أسعار — القرار (مجاني أو مدفوع، وبأي
  سعر) يُتخذ من بوابة الشركاء عند النشر.

