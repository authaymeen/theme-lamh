# لمح (Lamh) — ثيم سلة احترافي

ثيم متجر إلكتروني عام لمنصة سلة، مبني على محرك **Twilight** (Twig + SCSS + Tailwind).
هوية بصرية أنيقة ومينيمال: خلفيات بيضاء/رمادية محايدة + لون تمييز واحد (أخضر زمردي غامق `#0E7C6B`)،
مناسب لأغلب الأنشطة التجارية (أزياء، إلكترونيات، عطور، مستلزمات منزلية، إكسسوارات...).

## البنية

```
theme-lamh/
├── twilight.json              # إعدادات الثيم، الميزات، والمكوّنات المخصّصة
├── package.json / webpack.config.js / tailwind.config.js / postcss.config.js
├── src/
│   ├── assets/
│   │   ├── styles/            # app.scss + tokens + base + components + pages
│   │   ├── js/                # app.js + partials (main-menu, product-card...)
│   │   └── images/
│   ├── locales/               # ar.json / en.json
│   └── views/
│       ├── layouts/master.twig
│       ├── components/{header,footer,home,product}/*.twig
│       └── pages/              # index, product, cart, blog, brands, customer, ...
└── public/                     # ناتج البناء (مُتجاهل من git، يُنشئه webpack)
```

## المتطلبات قبل البدء

1. حساب شريك على [salla.partners](https://salla.partners).
2. حساب GitHub (سلة تربط الثيم بمستودع GitHub تلقائيًا).
3. Node.js (نسخة LTS حديثة) و **pnpm** (`npm i -g pnpm`) — الثيم مضبوط على استخدام pnpm فقط.
4. تثبيت [Salla CLI](https://docs.salla.dev/422774m0): `npm i -g @salla.sa/cli` ثم `salla login`.

## خطوات الربط والنشر (يجب تنفيذها من جهازك — سلة تتطلب مصادقة الشريك مباشرة ولا يمكن لأداة خارجية تنفيذها نيابة عنك)

1. أنشئ الثيم من بوابة الشركاء (My Themes → Create your first theme) أو عبر الأمر:
   ```bash
   salla theme create
   ```
   هذا يُنشئ مستودع GitHub فارغًا مرتبطًا بحساب الشريك.

2. استبدل محتوى المستودع الفارغ بمحتوى هذا المجلد (احتفظ بأي ملفات ولّدتها سلة تلقائيًا إن وُجدت
   ولا تتعارض)، ثم:
   ```bash
   git add .
   git commit -m "Initial Lamh theme"
   git push
   ```

3. ثبّت الاعتماديات:
   ```bash
   pnpm install
   ```

4. عاين الثيم مباشرة على متجر تجريبي مع Hot Reload:
   ```bash
   salla theme preview
   ```

5. عند الجاهزية للنشر في متجر القوالب:
   ```bash
   salla theme publish
   ```
   ثم أكمل بيانات صفحة الثيم في بوابة الشركاء (الأيقونة 250×250، لقطات الشاشة، الوصف، التصنيف،
   والتسعير إن كان الثيم مدفوعًا).

## نقاط تحتاج مراجعتك قبل النشر النهائي

- **الأيقونة/الشعار**: تم توليد نسخة أولية بسيطة في `src/assets/images/theme-icon.svg`
  (ونسخة PNG 250×250) بهوية "لمح" — راجعها/استبدلها بتصميم نهائي معتمد إذا رغبت.
- **لقطات شاشة المتجر**: تحتاج تجربة حقيقية على متجر تجريبي (Service Trial) لالتقاط لقطات فعلية
  بعد الربط — لا يمكن توليدها بدون بيانات متجر حقيقي.
- **صيغ حقول `twilight.json`** (خاصة `format: "color"` و `"select"` للإعدادات و`"category"` لمصدر
  المنتجات): ولّدناها بناءً على الأنماط الشائعة في ثيمات سلة، لكن يُنصح بمراجعتها سريعًا مقابل أحدث
  توثيق [Twilight.json](https://docs.salla.dev/421921m0) بعد الربط بالبوابة، لأن بعض القيم
  المسموحة قد تتغيّر بين إصدارات المحرك.
- **أسماء أيقونات سلة** (`sicon-*`) المستخدمة في مكوّن "مزايا المتجر": تأكد من مطابقتها لمجموعة
  أيقونات سلة الحالية من داخل بوابة الشركاء عند إعداد المكوّن.
- **الترخيص/التسعير**: هذا الثيم غير مربوط تلقائيًا بأي باقة أسعار — القرار (مجاني أو مدفوع، وبأي
  سعر) يُتخذ من بوابة الشركاء عند النشر.

## أوامر التطوير المحلي

```bash
pnpm run watch        # بناء تطويري مع مراقبة التغييرات
pnpm run production   # بناء إنتاجي مُصغّر
```
